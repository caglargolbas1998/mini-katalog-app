# mini_katalog_app
**Mini Katalog**, kullanıcıların giriş yaparak ürünleri inceleyebildiği, ürün detaylarını görüntüleyebildiği ve beğendikleri ürünleri sepete ekleyebildiği basit ve kullanıcı dostu bir mobil katalog uygulamasıdır.

Flutter 3.47.0 • channel stable

Mini Katalog Uygulaması Kullanım Adımları

Ana Sayfa
Ürünler listelenir.

Ürün görselleri, isimleri ve fiyatları görüntülenir.
Ürün Seçimi
Kullanıcı istediği ürünü seçer.
Ürünün bilgilerini inceleyebilir.
Ürün sepete eklenebilir.
Sepet Ekranı
Sepete eklenen ürünler görüntülenir.
Ürün adı, açıklaması, görseli ve fiyatı gösterilir.
İstenmeyen ürünler sepetten çıkarılabilir.


A new Flutter project.
